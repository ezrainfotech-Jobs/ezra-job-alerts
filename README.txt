EZRA JOB ALERTS - FULL VERSION

GOOGLE SHEET HEADERS (copy exactly):
Job Title | Department | Category | Qualification | Vacancies | Last Date | Apply Link | Status | Featured | Sponsored

Example:
TNPSC Group 2 | TNPSC | TNPSC | Any Degree | 500 | 30 Sep 2026 | https://example.com | New | Yes | No

CONNECT GOOGLE SHEETS:
1. Create the sheet with the headers above.
2. Add job rows.
3. Google Sheets -> File -> Share -> Publish to web.
4. Select the required sheet and CSV.
5. Copy the published CSV URL.
6. Open script.js and replace:
   const SHEET_CSV_URL = "";
   with your URL between the quotes.
7. Upload index.html, style.css and script.js to GitHub.
8. GitHub repository -> Settings -> Pages -> Deploy from branch -> main -> /(root) -> Save.
