EZRA JOB ALERTS — GOOGLE SHEETS + FULL JOB DETAILS

Files:
- index.html       Job listing homepage
- job.html         Full job details page
- style.css        Website styling
- script.js        Google Sheets loader + job details logic

GOOGLE SHEET HEADERS (recommended):
Job ID | Job Title | Department | Category | Short Description | Full Details | Post Name | Vacancies | Qualification | Age Limit | Salary | Application Fee | Selection Process | Job Location | Start Date | Last Date | How to Apply | Apply Link | Notification Link | Official Website | Status | Featured | Sponsored

IMPORTANT:
1. Keep the Google Sheet published as CSV.
2. Add one job per row.
3. Give every job a unique Job ID, e.g. TNPSC-001.
4. Paste the Apply Online URL in Apply Link.
5. Paste the PDF/notification URL in Notification Link.
6. The homepage card opens job.html?job=JOB-ID.
7. The detail page shows the complete job information FIRST. Apply Online / Notification / Official Website buttons appear at the bottom.
8. You do NOT need to edit script.js when adding or updating jobs; update the Google Sheet.

GITHUB PAGES:
Upload/replace index.html, job.html, style.css and script.js in the same repository folder. Keep all four files together.
